# 5. Dots and readability checks

[README](../README.md) | Prev: [4. Altitude / 3D locations](04-ALTITUDE.md) | Next: [6. Hashpaths in the Hashsite library](06-HASHPATHS-IN-HASHSITE.md)

---

Hashsite supports optional dots for readability and transcription checking.

Example:

```text
7B663IHXB8
7B6.63IH.XB8
```

The dotted and undotted versions refer to the same location.

Dots are derived from the code content and can work as a lightweight visual checksum.
