# 13. Companion product: Hashpath

[README](../README.md) | Prev: [12. Roadmap](12-ROADMAP.md)

---

Hashpath is the live companion product for multi-step real-world instructions.

Hashsite gives places compact codes.

Hashpath carries procedures around places: parking, gates, doors, access codes, dropoff points, exits, and other arrival details.

Hashpath lives here:

<https://hashpath.org>

This Hashsite documentation should mention Hashpath where relevant, but it should not become the Hashpath spec.
