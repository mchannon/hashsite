# 11. Design principles

[README](../README.md) | Prev: [10. Web app behavior](10-WEB-APP.md) | Next: [12. Roadmap](12-ROADMAP.md)

---

Hashsite should be open, compact, hierarchical, offline-capable, human-aware, 3D-native, and interoperable.

The map is an interface. The code is the object.

The codec should not require a network, account, API key, or rented permission.
